# Maintainer Notes

NWAS-Core should receive small, reviewable public updates.

Public updates should focus on architecture, governance, schemas, validators,
tests, and synthetic examples. Keep changes narrow enough that reviewers can see
the public/private boundary clearly.

Private NWAS knowledge packages remain separate and are not distributed here.
Do not publish private corpora, generated knowledge assets, deployment data
stores, real profile layers, or real evidence records in this repository.

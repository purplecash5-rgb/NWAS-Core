# Source Authority Model

NWAS-Core treats sources as governed records, not unstructured prompt material.

Each source record should declare:

- A stable source identifier.
- A lawful source type.
- A title or label suitable for display.
- Citation pointers that identify where supporting information came from.
- Review metadata when human approval is required.

Synthetic examples in this repository are not authority sources. They exist only
to exercise public schemas and validators.

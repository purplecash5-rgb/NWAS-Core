# No Third-Party Corpus Included

NWAS-Core includes no third-party corpus content.

It also includes no NWT text, no jw.org article text, no EPUB/PDF/HTML/audio/video
source material, no real evidence packets, no real embeddings, no SQLite
knowledge package, and no vector database.

The repository may mention these terms only in policy, disclaimer, or safety
documentation to make the exclusion clear.

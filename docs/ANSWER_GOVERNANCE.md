# Answer Governance

Governed answers should be constrained by evidence quality and review state.

Core rules:

- Drafts must cite an evidence packet.
- Weak evidence should produce cautious or insufficient-evidence modes.
- Missing citations should trigger review flags.
- The optional model layer may draft wording, but it may not invent authority.
- Private profile or corpus-derived records must remain outside this repository.

The schemas in `schemas/` provide a small public contract for these checks.
